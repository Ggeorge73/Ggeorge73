## Flagship: MyWowPet commerce delivery

MyWowPet is a decoupled e-commerce implementation combining a custom storefront, Firebase services, and Shopify commerce capabilities. The repository contains:

- Shopify product and variant mappings for a 24-product catalog
- Fail-safe purchase controls when a valid Shopify variant is unavailable
- Cart and checkout integration
- Playwright tests across desktop and mobile browser profiles
- GitHub Actions for linting, end-to-end testing, and scheduled regression runs
- DevSecOps gates using Gitleaks, Semgrep, and Trivy
- CI/CD configuration guidance for Shopify theme deployment and protected production environments
- Architecture, training, audit, and operational runbook documentation
